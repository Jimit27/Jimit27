### 🚀 Featured projects

#### 📉 [UK SME Distress Monitor](https://github.com/Jimit27/uk-sme-distress-monitor)
Early-warning model for UK company insolvency, built end to end from Companies House iXBRL filings. A GitHub Action scores the newest accounts every weekday and publishes a watchlist with plain-English reasons.

`ROC AUC 0.812 (out of time)` &nbsp; `47.9% of insolvencies in the riskiest 10%` &nbsp; `536,815 filings parsed`

[![Live demo](https://img.shields.io/badge/▶_Live_demo-FF4B4B?style=flat-square&logo=streamlit&logoColor=white)](https://uk-sme-distress-monitor-js27.streamlit.app/)
[![Code](https://img.shields.io/badge/Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Jimit27/uk-sme-distress-monitor)
&nbsp;dbt · DuckDB · LightGBM · SHAP · Streamlit · GitHub Actions

#### 💳 [Credit Risk Scorecard](https://github.com/Jimit27/credit-risk-scorecard)
Probability-of-default model built the way a lender needs it: PySpark medallion pipeline, Weight-of-Evidence scorecard, calibrated PDs, adverse-action reason codes, a profit-based cut-off and drift monitoring.

`Gini 0.712 on 29,892 holdout` &nbsp; `47× default spread, grade E vs A` &nbsp; `71 tests in CI`

[![Live demo](https://img.shields.io/badge/▶_Live_demo-FF4B4B?style=flat-square&logo=streamlit&logoColor=white)](https://credit-risk-scorecard-js27.streamlit.app)
[![Code](https://img.shields.io/badge/Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Jimit27/credit-risk-scorecard)
&nbsp;PySpark · Databricks · scikit-learn · XGBoost · MLflow

#### 🩻 [CausalXray](https://github.com/Jimit27/CausalXray)
MSc dissertation: pneumonia detection from chest X-rays with DenseNet-121, confounder adjustment for view position, and Grad-CAM heatmaps that show where the model looks.

`91% accuracy` &nbsp; `DenseNet-121` &nbsp; `Grad-CAM explanations`

[![Code](https://img.shields.io/badge/Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Jimit27/CausalXray)
&nbsp;PyTorch · Computer vision · Causal inference
